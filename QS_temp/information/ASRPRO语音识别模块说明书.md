# 永雏塔菲智能环境管家 — ASRPRO 语音识别模块说明书

> 芯片：天问 ASRPRO  
> 配合芯片：STM32U585CIU6  
> 更新：2026-06-20 最终版

---

## 一、模块概述

本模块基于天问 ASRPRO 离线语音识别芯片，实现**无需联网**的语音控制。ASRPRO 通过 UART 串口与 STM32U585 通信，支持 18 条命令词 + 传感器数据动态播报。

### 特性

- 离线识别，无需联网
- 唤醒词 + 命令词两级触发
- 动态传感器数值播报（温湿度、光照）
- 唤醒一次可连续多问，无需重复唤醒

---

## 二、唤醒方式

| 你说 | ASRPRO 回应 | 有效期 |
|------|------------|:---:|
| **"塔菲塔菲"** | "喵～ 塔菲在这里呢！" | 10 秒 |
| **"退下吧"** | "喵… 塔菲会想你的…" | 退出休眠 |

唤醒后 10 秒内可连续说多条命令词。每次播报完后自动延长 10 秒。超时后需重新唤醒。

## 三、全部语音命令

### 3.1 传感器查询（有语音播报数值）

| 命令词 | 播报示例 | 说明 |
|--------|---------|------|
| **"当前温度"** | "当前温度为 二十七 点 三 摄氏度" | 读 SHT40 |
| **"当前湿度"** | "当前湿度为 百分之 四十四 点 二" | 读 SHT40 |
| **"当前光照"** | "当前光照为 一千二百 勒克斯" | 读 BH1750 |
| **"环境状态"** | 依次播报 温 → 湿 → 光 | 三项全报 |

### 3.2 温度控制（步进 0.5°C）

| 命令词 | 效果 | ASRPRO 回应 |
|--------|------|------------|
| **"温度调高"** | 设定值 +0.5°C | "喵～ 调高了！" |
| **"温度调低"** | 设定值 -0.5°C | "喵～ 降低了！" |

### 3.3 湿度控制（步进 5%）

| 命令词 | 效果 | ASRPRO 回应 |
|--------|------|------------|
| **"湿度调高"** | 设定值 +5% | "喵呜～ 湿度调高了！" |
| **"湿度调低"** | 设定值 -5% | "喵～ 湿度降低了！" |

### 3.4 灯光控制（PB7 PWM）

| 命令词 | 效果 | ASRPRO 回应 |
|--------|------|------------|
| **"打开灯光"** | 100% PWM | "喵～ 灯亮了！" |
| **"关闭灯光"** | 0% PWM | "喵… 灯灭了！" |
| **"灯光调亮"** | +10% | "喵呜～ 更亮了！" |
| **"灯光调暗"** | -10% | "喵～ 暗一点了…" |

### 3.5 开关控制（手动模式）

| 命令词 | 效果 | ASRPRO 回应 |
|--------|------|------------|
| **"打开加热"** | PB0=高，强制加热 | "喵～ 加热已开启！" |
| **"关闭加热"** | PB0=低，强制关闭 | "喵～ 加热关闭了！" |
| **"打开加湿"** | PB1=高，强制加湿 | "喵呜～ 加湿器启动了！" |
| **"关闭加湿"** | PB1=低，强制关闭 | "喵～ 加湿器关掉了！" |
| **"自动模式"** | 恢复自动温湿度控制 | "喵～ 自动温湿度控制！" |

> 手动开关后自动进入"手动模式"，自动控制暂停。"自动模式"恢复。

## 四、硬件连接

| ASRPRO 引脚 | STM32 引脚 | 说明 |
|:----------:|:---------:|------|
| PB5 (UART0_TX) | PA1 (UART4_RX) | 数据发送 |
| PB6 (UART0_RX) | PA0 (UART4_TX) | 数据接收 |
| GND | GND | **必须共地** |

> UART 参数：9600 bps, 8N1, 无流控

## 五、动态数值播报说明

### 5.1 原理

ASRPRO **不支持实时 TTS 文本合成**，但内置数字解析引擎。本方案通过预录 0-9、十百千万亿等单字音频（playid 10084-10099），用 `play_audio` 函数动态拼接出任意数值语音。

### 5.2 播报流程（以温度为例）

```
STM32 发送 273 (= 27.3°C × 10)
  ↓ UART
ASRPRO 收到 → 拆分 v/10=27, v%10=3
  ↓
play_audio(10003) → "当前温度为"
speak(27)         → "二" "十" "七"
play_audio(10006) → "点"
speak(3)          → "三"
play_audio(10007) → "摄氏度"
  ↓
听到: "当前温度为二十七点三摄氏度"
```

### 5.3 数字音频 ID 表

| ID | 读音 | ID | 读音 |
|:--:|------|:--:|------|
| 10084 | 零 | 10093 | 九 |
| 10085 | 一 | 10094 | 十 |
| 10086 | 二 | 10095 | 百 |
| 10087 | 三 | 10096 | 千 |
| 10088 | 四 | 10097 | 万 |
| 10089 | 五 | 10099 | 负 |
| 10090 | 六 | 10006 | 点 |
| 10091 | 七 | 10007 | 摄氏度 |
| 10092 | 八 | 10009 | 勒克斯 |

## 七、开发注意事项

| # | 注意事项 |
|---|---------|
| 1 | 必须 `#include "myLib/asr_event.h"` 和 `#include "HardwareSerial.h"` |
| 2 | `Serial.begin(9600)` 必须在 `hardware_init()` 中调用 |
| 3 | **不要手写 IOREUSE 寄存器**，`Serial.begin` 自动配置引脚复用 |
| 4 | **不要用 `play_num`**，会导致芯片死机，使用 `speak()` 函数替代 |
| 5 | 查询类命令需 `delay(1200)` 等待 STM32 主循环处理 |
| 6 | `snid` 读取后必须清零，防止重复发送 |
| 7 | 播报完成后调 `set_state_enter_wakeup(10000)` 延长唤醒时间 |

## 八、通信协议

### 8.1 ASRPRO → STM32 命令帧（4 字节）

```
字节0: CMD   命令码 (0x10-0x54)
字节1: ARG   有符号参数 (int8)
字节2: 0x00  填充
字节3: 0x00  填充
```

### 8.2 命令码表

| CMD | 命令 | ARG |
|:---:|------|:---:|
| 0x10 | 查询温度 | — |
| 0x11 | 查询湿度 | — |
| 0x12 | 查询光照 | — |
| 0x13 | 查询全部 | — |
| 0x20 | 温度调高 | +1 |
| 0x21 | 温度调低 | -1 |
| 0x30 | 湿度调高 | +1 |
| 0x31 | 湿度调低 | -1 |
| 0x40 | 开灯 | — |
| 0x41 | 关灯 | — |
| 0x42 | 灯光调亮 | +1 |
| 0x43 | 灯光调暗 | -1 |
| 0x50 | 开加热 | — |
| 0x51 | 关加热 | — |
| 0x52 | 开加湿 | — |
| 0x53 | 关加湿 | — |
| 0x54 | 自动模式 | — |

### 8.3 STM32 → ASRPRO 回传

2 字节大端序 int16。温度/湿度为 ×10 后的值（如 27.3°C → 273），光照为原始 lux。

## 九、故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 语音无反应 | 未唤醒 / 模型有问题 | 先说"塔菲塔菲"唤醒 |
| 唤醒后命令无反应 | 接线错 / UART 不通 | 查 PB5→PA1、GND共地 |
| 播报数字偏一位 | ID 偏移计算错 | `10084 + n` 不能写成 `10085 + n` |
| 播报后卡死 | 用了 `play_num` | 改用纯 `play_audio` 拼播 |
| 播报后立即退出 | 误调 `enter_wakeup` | 删掉，只用 `set_state_enter_wakeup` |
| 烧录失败 | 未登录/编译模式错 | 登录+实名+选对 2M/4M |
| 数值和 OLED 不对 | delay 不够 | 查询类 `delay(1200)` |
