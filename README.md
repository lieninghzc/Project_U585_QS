# 智能环境管家 (STM32U585 + ASRPRO)

基于 STM32U585CIU6 的多功能环境监控与控制系统，支持温湿度调节、光照控制、语音交互与菜单操作。

---

## 硬件接线

| 外设 | STM32 引脚 | 说明 |
|------|-----------|------|
| SHT40 (温湿度) | PB10(PB10) SCL / PB11(PB11) SDA | I2C1 |
| BH1750 (光照) | PB10(PB10) SCL / PB11(PB11) SDA | I2C1 |
| OLED 0.96" 128×64 | PB12 SCL / PB13 SDA | 模拟 I2C |
| EC11 编码器 | PA6 TIM3_CH1 / PA7 TIM3_CH2 | 编码器模式 |
| 编码器按键 | **PB5** | 输入+上拉，按下=低 |
| LED (PWM调光) | **PB7** TIM4_CH2 | PWM, ARR=999→0.1%步进 |
| 加热器 | **PB0** | 推挽输出 (3.3V=加热) |
| 加湿器 | **PB1** | 推挽输出 (高电平=加湿) |
| ASRPRO 语音 | PA0 UART4_TX → ASRPRO RX | 9600 8N1 |
| | PA1 UART4_RX ← ASRPRO TX | 9600 8N1 |
| 板载 LED | PC13 | 无功能占用 |

> 编码器按键 PB5 与 ASRPRO 模块引脚无关，ASRPRO 的 UART TX 是其自身 PB5，连接 STM32 的 PA1。

## 软件架构

### 模块一览

| 模块 | 路径 | 职责 |
|------|------|------|
| `main.c` | `Core/Src/` | 初始化与主循环编排 |
| `SENS` | `Library/SENS.c/h` | 传感器聚合 (SHT40+BH1750+编码器) |
| `TSEN` | `Library/TSEN.c/h` | SHT40 温湿度驱动 (I2C) |
| `LSEN` | `Library/LSEN.c/h` | BH1750 光照驱动 (I2C) |
| `ENCODER` | `Library/ENCODER.c/h` | EC11 编码器驱动 (TIM3) |
| `OLED` | `Library/OLED.c/h` | SSD1306 OLED 驱动 (模拟I2C) |
| `DISPLAY` | `Library/DISPLAY.c/h` | 显示管理 (阴影缓冲/休眠/菜单高亮) |
| `Heating` | `Library/Heating.c/h` | 加热滞回控制 (PB0) |
| `Wet` | `Library/Wet.c/h` | 加湿滞回控制 (PB1) |
| `LED` | `Library/LED.c/h` | LED PWM PI负反馈调光 (BH1750闭环) |
| `VOICE` | `Library/VOICE.c/h` | ASRPRO 语音 UART 命令解析 |
| `MENU` | `Library/MENU.c/h` | 菜单系统 (按键+编码器, 休眠管理) |
| `DISPLAY` | `Library/DISPLAY.c/h` | OLED 休眠屏/激活屏/参数高亮 |

### 主循环流程

```
while (1) {
    SENS_Read();           // 读 SHT40 + BH1750 + 编码器
    Heating_Control();      // 温控滞回 (自动模式)
    Wet_Control();          // 湿控滞回 (自动模式)
    LED_Task();             // LED PI 负反馈调光
    DISPLAY_Update();       // OLED 刷新 (休眠/激活)
    MENU_Task();            // 按键/编码器检测 + 超时休眠
    VOICE_Process();        // UART 语音命令处理
    HAL_Delay(100);
}
```

## 菜单系统

### 操作方式

| 操作 | 功能 |
|------|------|
| **旋转编码器** | 唤醒 / 调节选中参数 / 确认 |
| **按下编码器按键 (PB5)** | 唤醒 / 循环切换选中参数 |
| **3分钟无操作** | 自动休眠 |

### 参数循环顺序

```
无选中 → 温度设定 → 湿度设定 → LED照度 → 模式切换 → 无选中
```

| 选中参数 | 编码器操作 | 说明 |
|---------|-----------|------|
| 温度设定 | 步进 ±0.5°C | 范围 10~80°C |
| 湿度设定 | 步进 ±1% | 范围 20~95% |
| LED照度 | 步进 ±100 lux | 范围 0~65535 |
| **模式切换** | **顺转→AUTO / 逆转→OFF** | **全部自动 / 全部关闭** |

### 模式说明

| 模式 | 加热器 | 加湿器 | LED | 自动滞回 |
|------|--------|--------|-----|---------|
| **AUTO** | 滞回自动 | 滞回自动 | PI闭环调光 | ✅ |
| **OFF** | 关闭 | 关闭 | 关闭 | ❌ 全部停止 |

## LED 闭环控制

基于 BH1750 实际照度反馈的 PI 负反馈控制：

```
目标照度 (lux) ─→ [偏差] ─→ PI控制器 ─→ PWM占空比 ─→ LED
                      ↑                                       │
                      └──────── BH1750 传感器 ←───────────────┘
```

| 参数 | 值 | 说明 |
|------|-----|------|
| PWM 分辨率 | 0.1% | ARR=999, 1000级 |
| 比例增益 Kp | 1.2 | |
| 积分增益 Ki | 0.03 | |
| 死区 | 50 lux | 偏差 ≤50 不动, 防震荡 |
| 控制间隔 | 500ms | 每5次主循环运算一次 |
| 光照滤波 α | 0.3 | 低通滤波 |
| 自适应速率 | 5%/3%/1%/0.5% | 越近越精细 |

## 语音控制 (ASRPRO)

### 命令列表

| 语音指令 | 命令码 | 动作 |
|---------|--------|------|
| "当前温度" | 0x10 | 回传温度 (×10) |
| "当前湿度" | 0x11 | 回传湿度 (×10) |
| "当前光照" | 0x12 | 回传光照 (lux) |
| "环境状态" | 0x13 | 回传温+湿+光 6字节 |
| "温度调高/低" | 0x20/0x21 | 步进 0.5°C |
| "湿度调高/低" | 0x30/0x31 | 步进 5% |
| "打开灯光" | 0x40 | `LED_ResumeAuto()` |
| "关闭灯光" | 0x41 | `LED_ForceOff()` |
| "灯光调亮/暗" | 0x42/0x43 | 步进 100 lux |
| "打开/关闭加热" | 0x50/0x51 | `voice_manual_mode=1` |
| "打开/关闭加湿" | 0x52/0x53 | `voice_manual_mode=1` |
| "自动模式" | 0x54 | `voice_manual_mode=0` |

### 状态共享

菜单和语音共用 `voice_manual_mode` 变量：
- `0` = 自动模式：`Heating_Control` / `Wet_Control` 根据滞回自动调节
- `1` = 手动模式：语音/菜单开关覆写，自动控制不干预
- 语音"自动模式" → 恢复为 0

> 详细 ASRPRO 编程参考 `DEVELOPMENT_GUIDE.md`。
